# Project Overview

## What is everyday HUB?

A **local discovery and booking social app** — think Instagram meets Yelp meets a booking platform — for finding nearby events, barbershops, wellness spots, fitness classes, nightlife, food, and more.

## Target Market

- People looking for things to do locally (Cleveland, OH launch city)
- Local businesses wanting discovery + booking without a full website
- Community organizers posting events

## Core Value Props

1. **Discover** — curated local feed by category, trending, and featured
2. **Book** — reserve spots at bookable venues directly in-app
3. **Save** — bookmark places you want to return to
4. **Review** — star ratings and written reviews
5. **Social** — like, comment, share posts

## Tech Stack

| Layer | Tech |
|---|---|
| Frontend | React + Vite + Tailwind |
| Backend | Express 5 + Node 24 |
| Database | PostgreSQL + Drizzle ORM |
| API Contract | OpenAPI 3 + Orval codegen |
| Monorepo | pnpm workspaces |

## Theme

Dark navy (`hsl(222, 58%, 13%)`) background with icy blue (`hsl(205, 65%, 68%)`) primary — matching the everyday HUB logo.

## Launch City

Cleveland, Ohio — 1,250 real local businesses seeded from OpenStreetMap.
