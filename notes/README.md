# everyday HUB — Project Notes

This folder is the Obsidian vault for the everyday HUB project.
All markdown files here live alongside the codebase and push to GitHub automatically.

## Folder Structure

```
notes/
├── README.md           ← you are here
├── Project Overview.md ← product vision & goals
├── Feature Roadmap.md  ← what's built, what's next
└── Session Log.md      ← running log of build sessions
```

> **Tip:** Install the [Obsidian Git](https://github.com/denolehov/obsidian-git) plugin and point it at the repo root to auto-sync notes with GitHub on every save.
